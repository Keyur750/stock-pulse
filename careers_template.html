Small team, honest about it.

Undertow is a solo, independent project today — not a company with a hiring pipeline. This page is here so that's clear, not to dress up something it isn't.

●

No open roles right now

Undertow is currently built and run by one person, on free infrastructure, as a personal project. There's no funding, no headcount, and no active hiring process — and it wouldn't be honest to list open positions that don't exist. If that changes, this page will say so plainly.

If it ever grows

The roles below aren't job postings — they're a sketch of the kind of people this project would eventually want around it, if it ever became more than a personal tool. Think of it as a wishlist, not a req.

DATA

Data Engineer

Someone who'd get excited about wiring up another independent signal source without breaking the "no black box" rule.

DESIGN

Product Designer

Someone who cares as much about how a number is labeled as what the number is — density without clutter.

RESEARCH

Quant / NLP Researcher

Someone who'd push the divergence classification and narrative taxonomy past first-pass heuristics, honestly.

COMMUNITY

Community / Trust

Someone who'd keep the project honest as it grows — no dark patterns, no paywalling transparency.

What we'd actually care about

Show the work

No shipping a number without a visible source.

Stay light

Free-tier-first, no cost creep, no dependency on someone else's paywall.

Say no to noise

A feature earns its place by cutting through clutter, not adding to it.
