ABOUT

A sentiment tool built to show its work.

Undertow is an independent, personal project — not a fund, not a data vendor. It exists because single-source sentiment tools weren't good enough to trust.

The problem

Most "retail sentiment" tools read one feed — usually just StockTwits or just Reddit — and present a bullish/bearish score with total confidence. But one feed capped at a few dozen posts a day is a thin basis for a real read. It's easy to mistake a loud minority for consensus.

Undertow started from a specific frustration: wanting to know what retail was actually thinking about a ticker, and not trusting a single-source answer enough to act on it.

"If four independent sources agree, that's worth something. If one loud feed disagrees with everything else, that's worth knowing too."

The approach

Instead of picking one feed, Undertow pulls from four: StockTwits (self-tagged bullish/bearish posts), Reddit's official API (r/wallstreetbets and friends), ApeWisdom (an independent mention-volume tracker), and financial news headlines scored for sentiment. Each source has a different bias and a different blind spot — which is exactly why corroboration across them means something a single feed can't.

Every ticker's mention count shows its source breakdown on hover, right in the dashboard. Nothing is asserted without showing where it came from.

How it's built

A Python script runs once a day on GitHub Actions' free tier, pulls from all four sources, scores sentiment with a VADER-based model tuned for retail trading slang, cross-checks it against real price action via Yahoo Finance, and writes a static dashboard page served by GitHub Pages. No server to maintain, no database, no subscription — which also means no incentive to gate features behind a paywall or optimize for engagement instead of usefulness.

What it isn't

Not financial advice. Not a trading signal service. Not a black box — every score traces back to a visible source. Sentiment reflects retail mood, not fundamentals, and signals highlight disagreement between chatter and price, not predictions.

A quick disclaimer

Undertow is for personal, non-commercial use. Nothing on this site is investment advice. Prices may be delayed. Do your own research.

What we hold to

Show the work

Every mention count breaks down by source. No unexplained numbers.

Corroborate, don't cherry-pick

Four sources that don't share a bias by construction.

Free by design

Running on free infrastructure removes the incentive to gate or manipulate.

Signal, not noise

Auto-flag the handful of things worth a second look, not everything.
