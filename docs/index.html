METHODOLOGY

Four sources. One confidence score.

Most sentiment tools read one feed and call it the crowd's opinion. Undertow corroborates across sources that don't agree with each other by default — so when they do agree, that means something.

PHILOSOPHY

Built on one simple idea

Sentiment tools that read a single feed and call it "the crowd" are guessing. We wanted a tool that shows its work — every ticker's mention count is broken down by source, right there in the UI, so you can see exactly how much data a read is built on.

No paywalled black box, no single point of failure. Free, public data sources, stitched together transparently, refreshed once a day for free on GitHub's own infrastructure — because an honest sentiment read shouldn't require a subscription.
